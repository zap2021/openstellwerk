# Sicherheit

Sicherheitslücken bitte **nicht** öffentlich als Issue melden, sondern per E-Mail an <mail@openstellwerk.de> (Betreff „Sicherheit“) oder über „Report a vulnerability“ im Reiter „Security“ dieses Repositories. Bitte kurz beschreiben, was passiert und wie man es nachstellt. Ich antworte so bald wie möglich.

Unterstützt wird jeweils die neueste Version (siehe Releases).
